# 画面設計（運用設計）

## 1. 情報構造（IA）

```
ホーム
今日の10問
科目A
 ├ テクノロジ
 ├ マネジメント
 └ ストラテジ
科目B
 ├ 擬似言語
 ├ アルゴリズム
 ├ データ構造
 └ セキュリティ
模擬試験
苦手問題
復習
成績
```

## 2. ナビゲーション

iPhone幅（375〜430px想定）ではボトムタブに7項目すべてを表示すると窮屈になるため、
主要4つ（ホーム／科目A/B／模擬試験／成績）をボトムタブに置き、
「今日の10問」はホームの一等地カード、「苦手問題」「復習」はホームカード＋ボトムタブの
「もっと」シートから遷移する構成とする。

```
[ボトムタブ]
🏠 ホーム | 📘 演習 | 📝 模試 | 📊 成績 | ☰ もっと

演習タブ = 科目A/科目Bのカテゴリ一覧（セグメントで切替）
もっとシート = 今日の10問 / 苦手問題 / 復習 / 設定
```

ホーム画面はこれらすべてへの導線を持つダッシュボードとし、要求仕様の名称
（ホーム/今日の10問/科目A/科目B/模擬試験/苦手問題/復習/成績）はすべてルーティング上の
ページとして実在させる（URL: `/`, `/daily`, `/subject-a`, `/subject-a/:category`,
`/subject-b`, `/subject-b/:category`, `/mock-exam`, `/weak`, `/review`, `/stats`）。

## 3. 画面詳細

### 3.1 ホーム
- 今日の学習ステータス（連続日数、今日の演習数、直近正答率）
- 「今日の10問をはじめる」大型CTAボタン
- 科目A/科目B進捗バー（カテゴリ別正答率のミニ表示）
- 苦手問題数・復習待ち数のバッジ
- 直近の模試スコア

### 3.2 今日の10問
- 全カテゴリから重み付き抽出（苦手問題・未回答を優先、正答率が高い問題は出現率を下げる）
- 1問ずつ表示 → 解答 → 即時正誤フィードバック＋簡易解説 → 次の問題
- 完了後にサマリー（正答数、カテゴリ内訳、苦手追加数）

### 3.3 科目A演習
- カテゴリ選択（テクノロジ／マネジメント／ストラテジ）
- カテゴリ内は出題数選択（5/10/20問）→ 4択形式で連続出題
- 各問後に解説表示、任意で「復習フラグ」を付与可能

### 3.4 科目B演習
- カテゴリ選択（擬似言語／アルゴリズム／データ構造／セキュリティ）
- 擬似言語・アルゴリズムのカテゴリでは、設問に**トレース実行パネル**を併設
  - 擬似言語コード表示（現在実行行をハイライト）
  - 変数状態テーブル（変数名・現在値、直前ステップからの変化をハイライト）
  - 操作: 「最初から」「ひとつ戻る」「次のステップ」「自動実行」
  - ステップ実行を最後まで確認した上で4択に解答する運用（先に答えを見て後から確認も可）
- データ構造・セキュリティのカテゴリは標準の4択＋解説（セキュリティは必要に応じて図表）

### 3.5 模擬試験
- モード選択: 科目A（90分・60問）／ 科目B（100分・20問）／ 通し（休憩を挟み両方）
- タイマー表示（残り時間、危険域で色変化）、途中中断・再開（localStorageに状態保存）
- 提出後に採点結果画面（総合スコア、分野別正答率、間違えた問題への復習フラグ一括付与）

### 3.6 苦手問題
- 誤答回数・直近正答率でソートされた問題リスト
- カテゴリフィルタ、「この問題だけ再演習」「苦手リストから外す」操作

### 3.7 復習
- 復習フラグを付けた問題、および誤答から一定期間内の問題を簡易間隔反復（正解すれば間隔を延伸、
  誤答なら翌日に再出題）で表示
- 「今日の復習」件数バッジ、完了までのプログレス

### 3.8 成績
- カテゴリ別正答率（横棒グラフ、SVGで自前実装）
- 学習履歴（日別演習数・正答率の推移、簡易折れ線）
- 模試スコア推移
- 総演習数・累計学習日数・連続学習日数

## 4. 状態管理・永続化方針

- グローバル状態: React Context + useReducer（軽量、追加ライブラリ不要）
- 永続化: `localStorage`（キー設計は `docs/03_data_model.md` 参照）、アプリ起動時にロード、
  変更の都度デバウンス保存
- 将来のサーバ同期を見据え、永続化層は `src/data/repository.ts` に抽象化し、
  実体（localStorage実装）を差し替え可能にする
