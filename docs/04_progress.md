## 開発中に発見・修正した実装上の問題

自動テストとE2Eテストを通じて、以下の不具合を開発中に発見し修正した（今後の開発の参考に記録）：

1. **論理演算`and`/`or`が短絡評価されていなかった** — `j >= 0 and arr[j] > key`のような式で、
   `j = -1`のときに`arr[-1]`を評価してしまい例外が発生していた。短絡評価を実装して解決。
2. **出題数選択ボタンのラベルが実際の値と食い違う** — 問題プールが10問しかないカテゴリで
   「20問」ボタンが「10問」と表示され、UIテストでの要素特定が曖昧になっていた
   （実質的にはユーザーにも紛らわしい表示だった）。ボタンの表示は選択肢の値そのものを表示し、
   プールが足りない場合はdisabledにするよう修正。
3. **復習フラグボタンのaria-labelが表示テキストと不一致** — アクセシビリティ上も
   WCAG 2.5.3（Label in Name）違反だったため、aria-labelを削除し表示テキストをそのまま
   アクセシブルネームとして使うよう修正。
4. **ヘッダーの`backdrop-filter`とbodyのスクロールアンカリングが、動的に高さが変わる
   質問カード（解答直後のフィードバック表示）と組み合わさって、ヘッドレスChromiumでの
   ヒットテストが不安定になっていた** — `backdrop-filter`を削除し、`body`に
   `overflow-anchor: none`を指定することで解消。これはPlaywrightのテスト環境固有の問題という
   より、実機でも稀に発生しうるスクロール周りの潜在的な不安定要因だったため、実装として修正した。
5. **GitHub Actions CIがPlaywrightの`webServer`起動待ちでタイムアウトしていた**
   （`Timed out waiting 60000ms from config.webServer.`）— `vite preview`を素の`--host`で
   起動するとGitHub Actionsのubuntuランナー上でIPv6（`::1`）にバインドされることがあり、
   Playwright側は`http://127.0.0.1:4173`（IPv4）を明示的に待ち受けていたため接続できなかった。
   `playwright.config.ts`の`webServer.command`に`--host 127.0.0.1`を明示して解消。
6. **問題バンク拡充後、「今日の10問」のE2Eでクリックのヒットテスト不安定化（#4と同種）が再発した**
   — トレース問題（擬似言語・アルゴリズム）の出題比率が上がったことで、設問が変わるたびに
   `TraceVisualizer`の有無でカード高さが大きく変動する頻度が増え、直後のクリックが
   前フレームの要素に奪われてリトライが延々と続くケースが発生。`overflow-anchor: none`は
   維持済みで根本原因のアニメーション等はコード上見当たらない。最初`.click({ force: true })`
   で対処したが、これは「disabledでないか」のチェックまで一緒にスキップしてしまい、
   直前の設問がまだdisabledのうちにクリックが空振りするリグレッションを起こした
   （繰り返し実行で逆に悪化することを確認）。最終的に`locator.dispatchEvent('click')`に
   変更し、座標ヒットテストを回避しつつdisabled要素へのclickは無視されるブラウザ本来の
   挙動を維持する形で解消（`--repeat-each=15`の連続実行で全件成功を確認。詳細はAGENTS.md参照）。
