# 基本情報技術者 Trainer — 要件定義書

## 1. 目的

「基本情報技術者 Trainer」は、iPhone（Webブラウザ／ホーム画面追加によるPWA運用）を中心とした、
基本情報技術者試験（FE）対策アプリである。ShijimiWORKsが運用する ProgrammingTrainer とは
別プロダクトとして開発する。既存の一般的な問題集アプリとの差別化点として、**科目Bの擬似言語問題を
1行ずつステップ実行し、変数の状態変化を可視化するトレース機能**を核とする。

## 2. 前提（2026年度 FE試験仕様）

- 科目A: 90分・60問・多肢選択（テクノロジ系／マネジメント系／ストラテジ系）
- 科目B: 100分・20問・多肢選択（擬似言語によるアルゴリズム・プログラミング問題が中心、加えて情報セキュリティ）
- 科目Bは特定言語（Java/Python等）を用いず、IPA共通の**擬似言語**の記法に従う
- IPAは2026年度出題の一部を公開しており、その傾向・難易度に合わせたオリジナル問題を作成する
  （設問文・コード・図表を含め独自作成し、公開済み問題の丸写しは行わない）

## 3. スコープ（本開発サイクルで実装する範囲）

止めることなく要件定義〜運用設計〜詳細設計〜実装〜テスト〜アプリ内簡易テスト〜完成まで実行する。
実装するコア機能は以下の通り。

1. ホーム（学習状況ダッシュボード、今日の10問への導線）
2. 今日の10問（科目A/Bを横断したデイリークイズ、苦手優先出題）
3. 科目A演習（テクノロジ／マネジメント／ストラテジ、カテゴリ別4択演習）
4. 科目B演習（擬似言語／アルゴリズム／データ構造／セキュリティ）
   - 擬似言語・アルゴリズム問題には**ステップ実行ビジュアライザ**を実装
5. 模擬試験（科目A: 90分60問 / 科目B: 100分20問、本番同様のタイマー付き通し演習）
6. 苦手問題（誤答した問題を自動収集、正答率の低い問題を優先表示）
7. 復習（フラグを立てた問題・直近の誤答を再学習するキュー、簡易間隔反復）
8. 成績（カテゴリ別正答率、学習履歴、模試スコア推移の可視化）

## 4. 非機能要件

- **プラットフォーム**: iPhone Safari を主対象としたレスポンシブWeb（PWA化。ホーム画面に追加してフルスクリーン起動可能）
- **オフライン動作**: Service Workerによる静的アセットのキャッシュ、データはブラウザのlocalStorageに永続化（サーバ不要、個人利用前提）
- **対応環境**: ユーザーの主端末が旧型iMac（2012年 / macOS Catalina）であるため、ビルド・開発環境は
  モダンブラウザ上での実行を前提とし、重厚なネイティブツールチェーン（Xcode等）に依存しない
- **技術スタック**: React + TypeScript + Vite（ProgrammingTrainerと統一）、Vitest（単体テスト）、
  Playwright（E2E／アプリ内簡易テスト）、ESLint
- **アクセシビリティ**: タップ領域44px以上、コントラスト比AA相当、フォントサイズ可変

## 5. 非スコープ（今回は対応しない／将来拡張）

- ネイティブアプリ化（App Store配信）、プッシュ通知
- サーバサイド同期・複数端末間の学習データ共有（将来的にはSupabase等を想定するが今回はローカル完結）
- IPA公開問題の完全収録（ライセンス上、参考にした独自問題のみ収録）
- 科目Bにおける擬似言語以外の言語対応

## 6. 成功基準（Definition of Done）

- 上記コア機能1〜8が実装され、Playwrightによるアプリ内簡易テストで主要導線が通ること
- 擬似言語ステップ実行ビジュアライザが、代入・条件分岐・繰り返し・配列操作を含む問題で正しく状態遷移すること
- Vitestによる擬似言語インタプリタの単体テストが全て合格すること
- ESLintエラーゼロ、ビルド（`npm run build`）が成功すること
- README / AGENTS.md / 自動開発スキルが整備され、今後のセッションでも開発を継続できること
